# Build roadmap

## Milestone 1 — Read the network (complete)

- Live devnet balance and transaction history
- Address validation and clear failure states
- Solana Explorer evidence links
- Unit tests and an opt-in live RPC integration test
- Responsive, production-buildable React interface

## Milestone 2 — Own progress on-chain (complete)

Installed and pinned tooling:

- Rust and Cargo
- Solana CLI configured for devnet
- Anchor Version Manager and a pinned Anchor CLI

Deliverables:

- Anchor passport and milestone PDA accounts
- Happy-path and unauthorized-access tests
- Seed-spoofing, oversized-input, and duplicate-milestone failure tests
- Generated IDL and typed Solana Kit client
- Devnet deployment with program and transaction Explorer links

## Milestone 3 — Issue proof

- Token-2022 non-transferable completion credential
- On-chain metadata linking the badge to the passport
- Frontend issuance and credential inspection flow

## Milestone 4 — Ship and explain

- Public deployment
- Architecture diagram and security checklist
- Two-minute product demo
- Application-focused case study explaining tradeoffs and lessons learned
